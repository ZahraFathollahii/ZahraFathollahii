# Zahra Fathollahi

I build accessible, type-safe web interfaces for healthcare, e-commerce, and security products: permission-aware forms, real-time flows, bilingual RTL/LTR UIs, and installable PWAs (3+ years in production).

---

## Focus

- **Architecture & Code Quality:** Modular front-end architectures applying SOLID design principles, Clean Code practices, and reusable design systems within Agile (Scrum/Kanban) workflows.
- **Complex Forms & Workflows:** Role-based access control (RBAC), multi-step clinical wizards, recoverable drafts, and safe saving with version checks and conflict handling.
- **Data Layer & Real-Time:** TanStack Query and Redux Toolkit with scoped query keys and explicit state transitions; live updates through SSE and WebSockets.
- **Bilingual Interfaces:** Persian/English localization with RTL/LTR mirroring, i18next, and Jalali calendars.
- **Performance & Testing:** Render and bundle optimization via memoization, code-splitting, and React DevTools, paired with Vitest unit/integration tests and strict TypeScript checks.
